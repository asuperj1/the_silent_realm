# KP 敏感词 / 指令过滤配置说明

## 文件位置

```
config/kp_filter.json
```

这是全服统一的过滤配置。修改**保存后即时生效**，**无需重启服务器**（系统按文件修改时间自动热加载）。

---

## 三组规则说明

| 配置项 | 作用 | 命中后效果 |
|--------|------|-----------|
| `irrelevantCommands` | 与副本无关的搞怪/现代行为（跳舞、发微信、点外卖…） | KP 不回应、**不扣回合值**、**不算行动**，私密提示 + 公共广播"指令未被回应" |
| `sensitiveWords` | 敏感词（脏话 / 攻击性 / 现实世界敏感内容） | 同上 + **公共频道广播自动脱敏**（敏感词替换为 `***`，避免不当内容传播给全队） |
| `metaCommands` | 元游戏/作弊指令（退出游戏 / 开挂 / 改存档…）。克苏鲁题材虚构法术/邪教属合法玩法，不做拦截 | 同「无关命令」，提示"列车只回应真实的行动" |

> ⚠️ 白名单保护：合法行动关键词（移动 / 搜索 / 检查 / 对话 / 道具等）会**优先放行**，即使文本中包含上面的词也不会被误拦。例如「把手机扔出窗外」不会因为含"手机"被拦（含"扔"属于合法动作）。若遇到合法行动被误拦，请在 `server/actionClassifier.js` 的 `REJECT_WHITELIST_RE` 中补充对应动作词。

---

## 怎么添加敏感词

打开 `config/kp_filter.json`，在 `sensitiveWords` 数组里**按行添加**即可：

```json
"sensitiveWords": [
  "脏话A",
  "脏话B",
  "/\\b攻击性词组+\\b/"
]
```

### 敏感词四类分组（内置清单已按此分类）

| 组 | 说明 | 示例 |
|----|------|------|
| **① 涉政敏感** | 现实当代政治：国家领导人/党政机构/现实时政事件/分裂反动词汇。禁止映射现实政治，**不影响虚构游戏内政权/邪教** | 台独、藏独、疆独、港独、法轮功、六四、天安门事件、反党、颠覆国家 |
| **② 辱骂 / 人身攻击** | 各类国骂、侮辱性脏话、针对玩家的人身攻击/嘲讽 | 傻逼、操你妈、王八蛋、贱人、脑残、智障、白痴、蠢货、去死 |
| **③ 歧视** | 种族/地域/性别性取向/残障歧视（不管 OOC 还是 IC 扮演一律严禁） | 黑鬼、基佬、死胖子、瘸子、瞎子、乡巴佬、外地佬 |
| **④ 高危内容** | 现实宗教亵渎、教唆自残自杀、儿童暴力性相关、现实毒品教唆、恐怖主义细节 | 自杀、自残、割腕、上吊、跳楼、吸毒、海洛因、冰毒、恋童、猥亵儿童、恐怖袭击、圣战 |

> 判断原则：**角色 IC 可以有角色愤怒呵斥，但不能使用现实脏话、人身攻击、网暴词汇；虚构游戏内邪教、克苏鲁信仰、异世界致幻药剂都没问题**，只拦映射现实的敏感内容。

### 两种写法

**① 普通词（推荐，最简单）**
直接写要屏蔽的词，命中玩家输入中包含该词的任何位置：

```json
"脏话A"
```
> 例：玩家输入「你真是脏话A」→ 命中并拦截。

**② 正则（进阶，适合屏蔽一类变体）**
用 `/.../` 包裹正则表达式，可拦截变形词：

```json
"/\\b傻[瓜叉Xx]+\\b/",
"/\\b[去][你您]妈\\b/"
```

> 正则语法就是 JavaScript 正则。注意 JSON 里反斜杠要写双份：`\b` 写成 `\\b`。

## 提示文案自定义

`reply` 字段可分别自定义三类提示语：

```json
"reply": {
  "irrelevant": "「……与本次探索无关，KP 无法回应。」",
  "sensitive": "「该内容不适合在本次探索中发送，已忽略。」",
  "meta": "「你无法在这里执行这个指令。」"
}
```

## 注意事项

1. **内置清单为初始版本**：`config/kp_filter.json` 已按上述四类预置了一批常见词（台独/傻逼/黑鬼/自杀/恋童等），可按需增删；国家领导人相关具体人名、更多时政词请按 `_comment` 说明自行补充。
2. **避免过度过滤**：敏感词影响玩家自由探索，建议只屏蔽明确不当内容；无关命令同理，保留合理自由度。
3. **白名单防误伤**：若玩家合法行动含敏感词子串（如「把垃圾扔出窗外」），因命中合法动作白名单会放行；如需收紧可调整 `server/actionClassifier.js` 的 `REJECT_WHITELIST_RE`。
4. **多人同步不受影响**：被拦截的指令不计入操作次数，也不影响全队回合推进判定（`exploreAllEnded`）。
