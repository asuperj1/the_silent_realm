# 青峰山虚空列车 · 完整游玩流程与剧情整合设计文档

> 版本：v2（2026-08-14）｜适用副本：废都纪元800｜青峰山虚空列车
> 本设计为「服务端实现 + KP 行为准则」的唯一权威来源。代码实现与本文档不一致时，以本文档为准。

---

## 0. 设计总览

**核心主题**：克苏鲁式"未知恐惧"——玩家在完全无知中苏醒，面对一列被虚空裹挟、空无一人的列车。**没有现成的世界观说明书，一切真相都要靠探索（线索物证）与冒险（对讲机、陈慧）逐步拼出**。怪物真名在收集到对应线索前绝不可知。

**三个新体验支柱**：
1. **沉浸开场**：昏迷醒来 → 环境描写 → 初始公文包（线索 + 对讲机）。
2. **对讲机支线**：唯一的外部联络通道，信号极差、电流音、对方自报身份——连接陈慧的救命线。
3. **条件触发战斗**：5号车等区域不再是"进去就打"，而是达成特定条件（翻看日记/发出声响/触发机关）才引怪，让探索有呼吸感。

## 1. 开场（昏迷醒来）—— 三段式唤醒（★ 双套开场白：单人 / 多人）

> 系统按房间人数自动切换：**单人游玩**用「你」个人视角；**多人合作**用「你们」团队视角（同车厢先后醒来、互相确认、各有一份公文包）。

### 1.1 环境描写（必播，全队可见）

> **单人版**
> 一阵尖锐的电流嗡鸣把你从黑暗中拽了出来。你躺在硬邦邦的座位上……你环顾四周：车厢里空无一人。……这列车上，似乎只有你一个人。

> **多人版**
> 一阵尖锐的电流嗡鸣把你们从黑暗中拽了出来。你们先后醒来，发现自己躺在同一节车厢的座椅上……你们彼此确认：没有人受伤，但这趟车上似乎只剩你们了。

### 1.2 引导性行动提示（开场必附）

> 【建议行动】
> ▸ 检查座位旁边的**公文包**（看起来不属于任何一个乘客）（回合值 0.5）
> ▸ 查看车厢内的**广播与紧急疏散图**（回合值 0.5）
> ▸ 起身**走向相邻车厢**，看看这列车到底还有没有人（回合值 0.5）

### 1.3 初始公文包（每个玩家座位旁都有一个）

打开公文包（行动或直接发放后查看）获得：

| 物品 | 类型 | 说明 |
|---|---|---|
| **陈旧的公文包** | 剧情 | 皮面磨得发亮，金属扣上刻着一行小字「G314 乘务组」。里面只有三样东西。 |
| **对讲机** | 线索物品（剧情） | 老式对讲机，频段标着 7。按下通话键，只有刺耳的电流杂音。**每 2 回合一次，开局可首呼**。（见 §3） |
| **乘务组交接便签** | 剧情线索 | 「乘务组交接记录——G314 次。昨晚 23:40 全组点名，列车长失踪；23:47 广播被外部信号劫持。**任何人听到广播，都不要信，不要前往 2 号车**。陈慧（乘务员）已前往 7 号车检修。本便签交新任值班员。若你看到这份便签，说明我们也失联了。」 |

> 公文包、对讲机、便签全部发放进背包「剧情道具」分区，并**投影到右边栏「线索记录」的线索物品栏**（像快捷栏投影背包物品），点击可查看金色浮窗。

### 1.4 开场关键设定

- **玩家初始什么也不知道**：不知道列车名、不知道发生了什么、不知道隧道通向哪里、不知道"乘客"是什么。
- **对讲机另一端不知道是谁**：第一次接通时，那边**自己报出身份**（电流音中传来一个女人的声音，先报"我是陈慧，G314 的乘务员"）。
- **广播**在开场 1 回合后自动响起（伪造广播，引导玩家去 2 号车集合——实为陷阱）。

## 2. 核心机制

### 2.1 回合值与行动（KP 动态判定）

- 每位玩家每大回合掷 1D6 作为**行动次数上限**（系统管理）。
- 每次行动由 KP 判定消耗 **【回合值】0.25~1**（轻量 0.25 / 常规 0.5 / 复杂 0.75 / 高风险 1）。
- 单玩家累计回合值 ≥ **1.5** → 本大回合强制结束，重新掷骰。
- 单人选项表格每行标注回合值。

### 2.2 属性判定（无骰子，纯阈值）

- 力量 STR / 敏捷 DEX / 体质 CON / 感知 PER / 意志 WIL，全部按固定阈值判定。
- 示例：PER≥50 才能看清便签；STR≥60 撬开角阀；WIL<60 见尸体扣 3 SAN。

### 2.3 线索 → 怪物真名解锁（克苏鲁未知恐惧）

| 怪物 | 模糊描述（未解锁） | 解锁线索 |
|---|---|---|
| 米·戈 | 粉红色湿黏肉块 / 发出人类呜咽的拟态生物 | L3 / L6 / L7 |
| 无形之子 | 从阴影渗出的柏油状黑色形体 | L2 / L7 |
| 修格斯幼体 | 盘踞通道口的巨大黑色粘液团 | L8 / L7 |

- 未解锁前：KP、知识库、战斗 UI 一律只能用模糊描述，**禁止直呼真名**。
- 解锁后：`【已识别生物】米·戈` 注入 KP 上下文，KP 方可直呼。

### 2.4 环境描写与引导提示（KP 硬性规则）

1. **每次场景转换**（进入新车厢、进出子空间、战斗开始/结束、广播响起）KP 必须重写一段环境描写（光线、声音、气味、动态细节），不得只报"你来到了 X 车"。
2. **每段回复的【可选方向】**至少给出 2~3 个**引导性行动提示**（含回合值），帮玩家决定下一步。
3. 环境描写要呼应"未知恐惧"：黑暗、粘液、电流声、门缝里的动静。

## 3. 对讲机支线（核心支线）

### 3.1 物品与使用

- **对讲机**（线索物品，入背包「剧情道具」分区，投影到右边栏线索记录）。玩家行动输入「用对讲机 / 呼叫 / 联系陈慧 / 7 频段」触发，或查看线索栏中的对讲机条目。
- **冷却**：每 **2 回合**可使用一次；**开局捡到即可首呼（无冷却）**；冷却中按下只有短促电流「啵」声，随即沉默。

### 3.2 电流音 + 自报身份（首次接通）

> 你按下通话键。「滋——滋啦——」电流声尖锐刺耳，几乎盖过一切。两三秒后，杂音被压下去，一个女人的声音断断续续地传来，**她先自报身份**：
>
> 「……滋——这里是陈慧。G314 次……乘务员。有人吗？有人在听吗？」
>
> 「……广播……别听广播的。我是人，我有呼吸，我有犹豫……那些声音没有。」
>
> 「滋——我在……7 号车……设备间。门卡死了……外面有东西在敲门。它……它学我说话……」
>
> （信号再次中断：「滋——沙沙沙——」）

### 3.3 后续可解锁信息（随线索进度，分阶段）

| 阶段 | 条件 | 对讲机获得的信息 |
|---|---|---|
| 初识 | 首次接通 | 自报身份；警告"别信广播"；她在 7 号车设备间 |
| 信任 | 玩家已收集 ≥2 线索 | 提示黑色柏油状的东西在车顶/走廊出没；建议带光源 |
| 指引 | 玩家已救出陈慧（L7） | 明确 8 号车有幼体、唯一生路在 8 号车尾侧壁 |
| 终局 | 逃生开启后 | 陈慧在另一端指挥："贴地爬，别回头，我在出口等你。" |

### 3.4 信号差的叙事价值

- 失败不是惩罚，而是**氛围**：电流声、半句话、被切断的身份信息，都在强化"孤立无援"与"它可能在监听"的恐惧。
- 高 PER（≥70）可在杂音中听出**背景里还有第二个呼吸声**——暗示这列车不只有你们。

## 4. 车厢与场景描写（8 节 + 子空间）

> 每节车厢进入时 KP 的环境描写要点 + 可探索物 + 触发点。

### 4 号车 · 餐车（出生点）
- **描写**：昏黄灯光、翻倒的餐桌、吧台后蒙灰的广播面板、厨房方向传来蒸汽嘶鸣。
- **探索**：吧台广播面板（L6，PER≥55）、厨房光源/急救包、餐柜食物。
- **特殊**：厨房里潜伏着"拟态生物"（米·戈），它会模仿人声求救——**不去招惹不会主动开打**，靠近/回应才触发。

### 3 号车 · 行李厢
- **描写**：行李堆成小山，冷风从破损车窗灌入，一只行李箱在列车转弯时自己滑了一下。
- **探索**：散落护照（L1，自动）、上锁工具箱（STR≥60 撬开，含撬棍）、窗外隧道里"粉红色湿黏肉块"沿车顶爬向 1 号车。
- **触发**：翻找动静大 → 柏油状黑色形体×2 从货堆缝隙渗出。

### 2 号车 · 二等座
- **描写**：座椅整齐得诡异，靠窗位置有一具"乘务员尸体"（是假的，米·戈拟态）、车顶滴落黑色粘液。
- **探索**：座椅缝便签（L2，PER≥50）、配电间（子空间）。
- **触发**：靠近车顶粘液/检查"尸体"太久 → 柏油状黑色形体×2 从车顶扑下。

### 1 号车 · 驾驶室（车头）
- **描写**：操控台被黑色粘液覆盖，列车长尸体倒在台前，仪表盘指针疯狂乱跳。
- **探索**：列车长尸体（L3，自动 + WIL 判定 SAN）、引擎室/应急柜。
- **触发**：进入即遭柏油状黑色形体×2 潜伏突袭（车头是"重灾区"）。

### 5 号车 · 卧铺（★ 条件触发战斗，见 §5）
- **描写**：一间间拉上帘子的卧铺，窗帘缝隙里似乎都躺着"人"，但掀开全是空铺。角落有一本摊开的日记。
- **探索**：日记（L4/L5）、手电筒、储物柜。
- **触发**：**不进入即打**。只有翻看日记 / 触动某扇被撬动的铺门 / 在车内发出大声响 / 停留超过 N 回合，才会惊动柏油状黑色形体×3。

### 6 号车 · 货物厢
- **描写**：邮件与货箱塞满通道，金属架间一片漆黑，有液体滴落声。
- **探索**：补给（弹药/食物）、货堆缝隙藏着的柏油状黑色形体×1。
- **触发**：翻找声 → 惊动。

### 7 号车 · 乘务设备厢（陈慧）
- **描写**：走廊尽头传来有节奏的**敲击声**——是活人。设备间门被塌落的货架卡死。
- **探索**：陈慧（敲门表明来意 / STR≥55 破门）、求救便签。
- **触发**：门外徘徊的柏油状黑色形体×2；救出陈慧 = L7（解锁全部真名）。

### 8 号车 · 尾厢（boss 区）
- **描写**：毒雾弥漫、灯光只能照清三步内。通道口盘踞着"巨大黑色粘液团"（修格斯幼体）。
- **探索**：毒雾（站立 3 伤/爬行 1 伤）、侧壁紧急疏散通道（STR≥60=1 回合，否则 3 回合）、工程图（L8）。
- **触发**：进入即进入 boss 战（3 盏光源或累计 50 伤害驱退，3 回合未驱退即死判定）。

## 5. 5 号车条件触发战斗设计

**原则**：5 号车（卧铺）是最适合"心理恐怖"的车厢——安静、密闭、看似安全，实则暗藏杀机。**进入不战斗，条件触发才战斗**。

### 5.1 触发条件（满足任一）
1. **阅读日记后页（L5）**——读完后放下日记的瞬间，阴影里的东西动了。
2. **打开被撬动的 3 号铺门**——门后躺着什么，但你想看的瞬间，它看向你。
3. **在车内发出大声响**（砸门、喊叫、打翻东西）。
4. **停留超过 3 个行动回合**且做过 2 次以上翻找——"它"觉得你发现了太多。

### 5.2 触发表现
- 触发瞬间：窗帘全部落下、灯光熄灭一瞬、床铺底下传来粘稠的蠕动声。
- 柏油状黑色形体×3 从床底/帘后/天花板渗出，进入战斗。
- 未触发时：玩家可安全搜完 L4/L5、手电筒、储物柜再离开。

### 5.3 状态字段
- `state.carStates.car_5_sleeper.formlessTriggered`（false → 进入不引怪；true → 触发战斗）。
- 触发由副本逻辑在满足条件时置位（见服务端实现）。

## 6. 主线流程（推荐探索顺序）

```
开场（昏迷醒来）→ 公文包/对讲机 → 4 号车探索
   │
   ├─ 对讲机联系陈慧（支线开线）
   ├─ 3 号车（L1 护照 + 撬棍）→ 1 号车（L3 尸体）
   ├─ 2 号车（L2 便签）→ 5 号车（L4/L5 日记，条件触发战斗）
   ├─ 6 号车（补给）→ 7 号车（救陈慧 L7，解锁全部真名）
   └─ 8 号车（L8 工程图 + boss 战 + 逃生通道）→ 结局
```

- **必收集线索**：L1、L3、L4、L5、L7（陈慧）为真相关键；L2、L6、L8 强化判断。
- 真相层级：≥3 条 = 碎片真相；≥5 条 = 拼图真相；≥7 条 = 完全真相。

## 10. 服务端实现要点（与代码对应）

1. **开场**：`qingfengTrain.processEntryBroadcast` 输出「昏迷醒来环境描写 + 公文包提示 + 引导行动」（三段式）。
2. **初始物品**：副本开启（copyStart）时给每名玩家发放「陈旧的公文包」「对讲机」「乘务组交接便签」。
3. **对讲机**：`battleHandler` 识别行动关键词（对讲机/呼叫/联系陈慧），触发 `walkie` 逻辑——概率失败（电流音）+ 首通自报身份 + 分阶段情报。
4. **5 号车**：`getSpaceMonsters` 对 `car_5_sleeper` 检查 `state.carStates.car_5_sleeper.formlessTriggered`；满足 §5.1 条件时置位。
4. **对讲机冷却**：`battleHandler` 对讲机分支用 `room._walkieLastTurn` 记录上次使用回合，`room.turn - lastTurn < 2` 且已使用过 → 冷却静默；首次使用（lastTurn 未设置）无冷却。
5. **线索记录栏投影**：`cluePanel.js` 线索物品栏改为投影所有 `type==='plot'/'clue'` 背包物品（图标 + 描述 + 金色浮窗），公文包/对讲机/便签/CLUE-Lx 全部显示。
6. **双套开场白**：`processEntryBroadcast(state, playerAttr, isSolo)`，`gameHandler` 按 `gameRoom.players.size <= 1` 传单人/多人。
7. **场景描写**：`deepseekClient` 系统提示词强化「每次场景转换必须环境描写 + 每次回复必须引导性行动提示」。
