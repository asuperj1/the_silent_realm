## 四、提示词策略

- 统一风格：克苏鲁恐怖场景插画，深色烟雾、昏暗灯光、戏剧性侧光、厚涂油画、电影感、超写实、无文字（宽幅横构图）
- **正常**：只描述车厢环境细节（压抑安静、尚无怪物）
- **遇怪**：在环境描述后追加怪物现身（无形之子：黑色原生质体、眼球拟足；米·戈：粉红节肢生物、脑罐）
- **车内观察**（外隧道点）：透过车窗向内窥探视角，车窗玻璃反光与隧道幽蓝裂隙光交织，车内景象在玻璃后隐约可见
- NEGATIVE：禁文字/水印/UI/边框等

## 五、脚本与运行

- 脚本：`tools/gen_qingfeng_scenes.js`（复用即梦批量模式：串行 2.5s、限流防护、幂等跳过、日志 `logs/qingfeng_scenes.log`；宽幅 1280×720）
- 用法：
  ```bash
  node tools/gen_qingfeng_scenes.js all          # 全量 41 张（约 10-12 分钟）
  node tools/gen_qingfeng_scenes.js 1号车驾驶室    # 单点 2 张（车厢点）
  node tools/gen_qingfeng_scenes.js 3号车外隧道    # 单点 3 张（外隧道点含车内观察）
  node tools/gen_qingfeng_scenes.js 隧道          # 关键字过滤
  ```
- 限流：命中每分钟上限自动等待 65s 重试；每日额度用尽自动终止（可调 `api_rate_limit.js`）
