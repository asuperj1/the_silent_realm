# 杀戮尖塔 2 式战斗系统设计 v2.2（以技能 / 普攻 / 装备 / 消耗品为准）

> **版本**: v2.2（v2.1 基础上 P0-P3 已全部实施落地）
> **日期**: 2026-08-15
> **状态**: 已实施（P0 引擎/P1 意图格挡状态/P2 装备被动换装资源条/P3 SAN召唤战利品）
> **实施记录**：`/memories/repo/coc-rpg-game-debug.md` 顶部各阶段条目
> **v2.0 核心修正**：
> 1. **能量骰保留原设定**（武士/小丑/警官 2D6、炼金 4D6、其余 3D6）——最多能量上限与骰子次数与现有配置完全一致，不做缩放。
> 2. **每职业普攻/技能费用差异化**——具体数值由本设计给出（§5 职业面板）。
> 3. **法师普攻=物理伤害**，技能才是法系输出核心；物理/敏捷职业普攻是主要输出通道。
> 4. **专属资源条机制**（酒意/战意/炁/子弹/怒气/星能/魔能/剂量/探知值/战力/禅意/狂欢能量/正义值），**严格区分主动资源与被动机制**——如武士「架势条/招架」是被动技能，不主动消耗。
> 5. **武器改变攻击方式**——weapon 槽决定普攻模板（近战/枪械/法器/重武/拳刃/盾击）。
> 6. **战斗中（小局）更换装备消耗能量**（AP），换装是战斗内的高代价策略动作。
> **v2.1 新增**：
> 7. **武器基础伤害 baseDmg**——普攻伤害以**武器自身基础伤害**为准（空手 = 角色物攻）。例：方士空手普攻 22（物攻），拿上 baseDmg 50 的手枪 → 普攻 50。角色属性不直接加成普攻，成长来自换更强武器（§5.1 / §6）。

## 0. 一句话概述

> 战斗是**回合制数值博弈**：每回合掷职业能量骰获得**能量（AP）**，用 **技能 / 普攻 / 消耗品** 执行行动、**换装备**消耗能量；**武器决定普攻方式**；**装备提供常驻属性与战斗被动**；怪物头顶**显示意图**；**格挡与状态**在回合边界结算。数值由引擎裁决，KP 退居叙事与场外判定。每个职业有**专属资源条**——有的主动消耗（弹药/炁/星能…），有的被动触发（武士架势、百夫长战姿、警官正义处决）。

## 1. 设计目标与核心原则

| # | 原则 |
|---|------|
| P1 | **能量是唯一硬预算**：所有行动（普攻/技能/消耗品/**换装**）都从本回合掷出的能量中扣费 |
| P2 | **普攻物理、技能分系**：普攻一律走物理通道；法系职业靠技能打输出，物理职业靠普攻+技能 |
| P3 | **武器决定攻击方式**：换武器 = 换普攻模板 |
| P4 | **专属资源条 = 职业灵魂**：主动资源供技能消耗；被动机制自动触发（不可手动消耗） |
| P5 | 引擎裁决数值，KP 润色叙事；战斗内不掷判定骰 |
| P6 | 保留克苏鲁未知恐惧锁（锁名不锁行为）与探索回合值共存 |

## 2. 战斗回合结构

```
battleStart
  ├─ 初始化战场：玩家战斗快照、怪物满血、回合=1、格挡/状态清空、意图抽取
  ├─ 玩家回合开始（battleTurn）
  │    ├─ ① 结算持伤（中毒/灼烧）→ ② 玩家格挡清零 → ③ 掷职业能量骰得 AP
  │    ├─ ④ 结算 onTurnStart 被动/装备词条 → ⑤ 广播敌人意图
  │    └─ ⑥ 等待玩家行动
  ├─ 玩家行动循环（AP 够可连续行动）
  │    ├─ 普攻 / 技能 / 消耗品 / 换装备 / 结束
  │    └─ 引擎结算 → battleEvent
  ├─ 玩家回合结束（主动 或 AP 不足）
  ├─ 敌人回合（battleEvent type=monster）
  │    ├─ ① 每个存活怪物按意图行动 → ② 怪物格挡清零
  │    └─ ③ 结算玩家持伤
  ├─ 回合+1 → 回「玩家回合开始」
```

**时序协议**：
| 时间点 | 触发 | 结算顺序 |
|--------|------|---------|
| T0 战斗开始 | 装备/被动 `onBattleStart`、怪物抽意图 | 玩家被动 → 怪物意图 |
| T1 玩家回合开始 | 持伤→清玩家格挡→掷 AP→被动/词条→意图 | 持伤 → 清格挡 → AP → 被动 → 意图 |
| T2 玩家行动 | 普攻/技能/消耗品/换装 | 按效果数组顺序 |
| T3 敌人回合 | 怪物按意图行动；怪物格挡清零 | 按怪物 index |
| T4 回合结束 | 状态衰减、回合+1 | 玩家 → 怪物 |

## 3. 能量体系（保留原能量骰设定）

### 3.1 每回合能量 = 职业能量骰原值
> 能量骰来自 `professions.json / skill_tree.json` 现有配置，**不改动**。

| 能量骰 | 职业 | 每回合掷骰次数 | 单回合能量范围（上限=骰数×6） |
|--------|------|--------------|------------------------------|
| **2D6** | 武士 / 诡术小丑 / 警官 | 2 次 | 2 ~ **12** |
| **3D6** | 海盗/角斗士/方士/枪手/骑士/观星者/环法师/侦探/百夫长 | 3 次 | 3 ~ **18** |
| **4D6** | 炼金术师 | 4 次 | 4 ~ **24** |

- 每回合能量**不跨回合累计**，回合开始重新掷骰。
- 能量由 `onTurnStart` 词条可 +1/+2（装备被动）。
- 上限即骰子数×6（掷出上限值时该回合能量满额）。

### 3.2 为什么保留大能量量级
- 能量量大 → **技能费用也按职业定高**，一回合仍只够 2~5 次有效行动，保持"能量有限 → 策略取舍"。
- 换装、消耗品与部分"高费大招"共同吃掉预算。

## 4. 普攻 / 技能 / 消耗品 / 换装 费用体系

### 4.1 费用总表（基准，每职业见 §5 微调）
| 行动 | 基准费用 | 说明 |
|------|---------|------|
| **普攻** | 2 ~ 4 | 由职业 + 武器类型决定 |
| **技能** | 4 ~ 10 | 由职业 + 品级（normal/good/epic/s）决定 |
| **消耗品** | 0 ~ 2 | 药水 0 / 投掷道具 2 |
| **换武器** | 5 | 战斗内更换 weapon 槽 |
| **换防具/饰品** | 3 | 更换 head/body/hand/foot/accessory |
| **结束回合** | 0 | 主动结束 |

> **换装是战斗内高代价动作**：本回合掷出的能量被"锁"一部分用于换装，换完立即生效（新被动/新属性/新普攻模板），但下回合重新掷骰——换装 = 用当前回合行动力换长期收益。

## 5. 职业面板（每职业差异化：普攻 / 技能 / 专属资源）

> **定位三系**：法系（普攻=物理弱、技能=法系核心）、物理战士（普攻=主要输出）、敏捷/刺客（普攻=多段连击）。
> **普攻一律物理通道**（物攻 physAtk），**技能按职业分物理/法系通道**。

| 职业 | 定位 | 能量骰 | 普攻 AP | 技能 AP | 专属资源 | 资源机制类型 |
|------|------|--------|--------|---------|---------|-------------|
| 方士 | 法系 | 3D6 | 2 | 5~8 | 炁 | **主动**（技能耗炁，普攻回炁） |
| 观星者 | 法系 | 3D6 | 2 | 6~9 | 星能 | **主动**（每回合被动回星能，大招耗星能） |
| 环法师 | 法系 | 3D6 | 2 | 6~10 | 魔能/魔环 | **主动**（技能耗环，环数=叠层上限） |
| 炼金术师 | 法系 | 4D6 | 2 | 4~7 | 剂量 | **主动**（剂量=多段灵活，技能耗剂量） |
| 角斗士 | 战士 | 3D6 | 3 | 4~8 | 战意 | **主动**（受击/攻击累积战意） |
| 骑士 | 坦克 | 3D6 | 3 | 5~9 | 怒气 | **主动**（受击累积怒气） |
| 百夫长 | 战士 | 3D6 | 2 | 5~8 | 战力/五段战姿 | **被动**（连击段数被动增强，不消耗） |
| 海盗 | 战士 | 3D6 | 3 | 4~7 | 酒意 | **主动**（攻击累积酒意） |
| 枪手 | 敏捷/远程 | 3D6 | 4 | 5~9 | 子弹 | **主动**（普攻耗弹，装弹技能回弹） |
| 侦探 | 敏捷 | 3D6 | 2 | 5~8 | 探知值 | **被动+主动**（观察累积探知，技能耗探知标弱点） |
| 武士 | 战士 | 2D6 | 2 | 4~8 | 禅意/架势 | **被动**（架势条=招架/架势，受击与闪避累积，自动触发，不主动消耗） |
| 诡术小丑 | 敏捷 | 2D6 | 2 | 4~7 | 狂欢能量 | **主动**（暴击回狂欢，戏法耗狂欢） |
| 警官 | 爆发 | 2D6 | 3 | 5~8 | 正义值 | **被动+主动**（累积正义值，满值自动「正义处决」） |

### 5.1 普攻设计（武器基础伤害 = 普攻伤害主体）
- **普攻伤害 = 武器基础伤害 `baseDmg`**（§6.2 数值表）；**空手/徒手 = 角色物攻 `physAtk`**（如方士 22 → 打 22 物理伤害）。
- 法系普攻 = **近战物理敲击**（法杖/徒手/法器），`baseDmg` 低（12~22），但可回专属资源（炁/星能等），是法系"产资源+应急"手段。
- 战士普攻 = **重击**（`baseDmg` 中高 22~55），是主要输出通道。
- 敏捷普攻 = **多段连击**（2~3 段，各段 = `baseDmg ÷ 段数`），触发多次 onAttack 与武器词条。

### 5.2 技能设计（物理/法系通道）
- **法系技能**：`magAtk` 加成，白字高，是法系输出核心（方士炁系、观星星术、环法魔环、炼金剂量爆发）。
- **物理技能**：`physAtk` 加成，战士/刺客技能是爆发/控制/防御（角斗士裂伤、骑士战吼、武士居合、枪手狙击）。
- 技能品级费用基准：normal 4~5 / good 5~6 / epic 7~8 / s 9~10（法系大招最高）。

### 5.3 专属资源条机制（核心区分：主动 vs 被动）
| 类型 | 含义 | 职业举例 |
|------|------|---------|
| **主动资源** | 技能**消耗**该资源；通过普攻/受击/被动回复 | 枪手·子弹、方士·炁、观星·星能、环法·魔环、炼金·剂量、角斗·战意、骑士·怒气、海盗·酒意、小丑·狂欢 |
| **被动机制** | **不主动消耗**，由条件自动累积并自动触发 | 武士·架势条（受击/闪避→自动招架）、百夫长·五段战姿（连击段数自动增强）、警官·正义值（满值自动处决） |

> **武士示例**：架势条不是可主动点的"技能"，而是被动——每次受击/完美闪避累积架势，达到阈值自动触发「招架」抵消下一次攻击 /「架势」提升下次伤害。玩家无法手动"消耗架势"，只能通过站位/格挡节奏去累积。

## 6. 武器系统（改变攻击方式）

### 6.1 武器类型 → 普攻模板
| 武器类型 | 普攻 AP | 普攻模板（baseDmg 区间） | 特点 |
|---------|--------|------------------------|------|
| **剑/刀（单手）** | 3 | 物理单段 `baseDmg 25~45` | 均衡 |
| **重武器（双手/巨刃）** | 4 | 物理单段 `baseDmg 40~70` + 破甲 | 高伤慢速 |
| **枪械（远程）** | 4 | 物理多段 2~3 段，`baseDmg 30~55`（合计） | 远程、**消耗弹药资源** |
| **法器/法杖** | 2 | 物理敲击 `baseDmg 12~22` | 低伤，**强化技能法伤**（+magAtk×0.2） |
| **匕首/拳套** | 2 | 物理多段 3 段，`baseDmg 18~32`（合计） | 高速连击 |
| **盾+武器** | 3 | 物理单段 `baseDmg 22~40` + 获得格挡 4 | 攻防一体 |

### 6.2 武器基础伤害数值表（baseDmg，按品质 × 类型）
| 品质 | 近战 melee | 远程 ranged | 法器 focus | 现有武器示例 |
|------|-----------|------------|-----------|-------------|
| 白 | 16~22 | 22~28 | 12~16 | 生锈拆解刀(QFSE002) **18** |
| 绿 | 22~30 | 30~38 | 16~22 | 猎刀(G-024) **24** / 列车撬棍(QFSE001) **26** / 简易手枪(QFSE003) **34** |
| 蓝 | 30~42 | 40~55 | 22~30 | 左轮手枪(G-023) **50** / 双管霰弹枪(QFSE004) **55** |
| 紫 | 42~55 | 55~70 | 30~40 | （待补充） |
| 橙/黑 | 55~80 | 70~95 | 40~55 | 修格斯核心残片(QFSE013) **72** |

> 用户例子核对：方士空手普攻 22（物攻）；拿上**左轮手枪（蓝·远程 baseDmg 50）** → 普攻 **50**。✓

### 6.3 普攻伤害公式（唯一，引擎裁决）
```
普攻伤害 = 武器 baseDmg        // 装备武器时
         = 角色物攻 physAtk    // 空手/徒手时（baseDmg 缺失/为 0）
多段普攻：baseDmg 按段数均分（每段 = round(baseDmg / hits)）
命中后走减伤链：护甲减免(穿透) → 格挡 → HP（§9.2）
```
- **主属性不直接加成普攻**（武器本体决定数值）；角色成长体现为能换更强武器。
- 力量状态（strength）、易伤（vulnerable）等**乘区**仍作用于普攻（见 §9）。

### 6.4 武器数据模型（新增 `baseDmg` 字段，写入现有武器配置）
```json
{ "itemId": "G-023", "itemName": "左轮手枪", "type": "equipment", "slot": "weapon",
  "weaponKind": "ranged", "quality": "blue",
  "baseDmg": 50, "ap": 4, "hits": 1,
  "effects": [ { "trigger": "onEquip", "kind": "stat", "stat": "str", "value": 2 } ] }
```
> 现有武器（G-023/G-024、QFSE001~004/013）已有 `weaponKind`，只需按 §6.2 补 `baseDmg/ap/hits` 三字段；空手 = 物攻由引擎兜底。

### 6.5 换武器 = 换攻击方式
- 战斗中更换 weapon 槽消耗 **5 AP**，换后 baseDmg、普攻模板、武器词条、属性立即刷新。
- 换防具/饰品消耗 **3 AP**，被动/属性立即刷新。
- 换装界面 = 现有六槽装备界面，战斗内可打开（新增"战斗中"状态）。

## 7. 消耗品（战斗行动）

### 7.1 规则
- 战斗中从快捷栏使用消耗品：`battleAction {action:'item', itemUid}`。
- 费用 0（药水）/ 2（投掷伤害道具）。
- 复用 `EffectEngine.useItem`，在战斗上下文结算（hp/san/stat buff/shield/damage/statusEffects）。
- **每回合最多使用 1 个消耗品**。

### 7.2 战斗效果示例
| 物品 | 费用 | 战斗效果 |
|------|------|---------|
| 浓血 | 0 | HP +35 |

| 急救包 | 0 | HP +20 |

## 8. 敌人意图系统（杀戮尖塔核心）

### 8.1 意图数据模型
```json
{
  "type": "formless_spawn",
  "name": "无形之子",
  "hp": 55, "maxHp": 55,
  "dex": 15, "def": 3, "magDef": 2,
  "intents": [
    { "move": "attack", "label": "撕咬", "dmgBase": 4, "scale": "physAtk", "ratio": 0.4 },
    { "move": "block",  "label": "蠕动护体", "block": 6 },
    { "move": "buff",   "label": "狂暴化", "self": { "id": "strength", "value": 1, "turns": 1 } },
    { "move": "debuff", "label": "粘液喷吐", "effect": { "id": "weak", "value": 1, "turns": 1 } }
  ],
  "loot": "formless_spawn"
}
```
- `move`: `attack | block | buff | debuff | summon | charge`
- 意图每回合切换：默认数组顺序循环；BOSS/精英可随机。
- **怪物血量基准（适配武器 baseDmg）**：普通小怪 45~70（2~4 次普攻可清）、精英 120~180、BOSS（修格斯）300~500——具体在 `config/battle_monsters.json` 平衡。

### 8.2 意图结算与 UI
- T1 广播当前意图（`battleIntent`），T3 执行。
- 怪物立绘头顶气泡：`⚔撕咬8（红）/ 🛡格挡6（蓝）/ ✨狂暴+1力（金）`。
- **克苏鲁锁只锁名字，不锁行为**：未解锁怪物意图气泡显示「？？？」图标，但数值可读（可预测 → 策略性）。

## 9. 格挡与状态系统

### 9.1 状态标准表
| 状态 id | 类型 | 效果 | 结算点 |
|---------|------|------|--------|
| `strength` 力量 | buff | 伤害 +10%/层 | 伤害计算 |
| `weak` 脆弱 | debuff | 攻击 -25%/层 | 攻击时 |
| `vulnerable` 易伤 | debuff | 受伤害 +50%/层 | 受击时 |
| `poison` 中毒 | debuff | 每回合 2×层数（无视防御） | T1/T3 |
| `burn` 灼烧 | debuff | 每回合 3×层数 | T1/T3 |
| `blockUp` 格挡增强 | buff | 获得格挡 +50% | 获格挡时 |
| `dexUp` 敏捷 | buff | 闪避 +10%/层 | 受击时 |
| `immobilize` 禁锢 | control | 无法行动 1 回合 | 行动时 |
| `stun` 眩晕 | control | 跳过回合 | 行动时 |
| `regen` 再生 | buff | 每回合回 3×层数 HP | T1/T3 |
| `shield` 护盾 | buff | 吸收伤害 | 受击时 |

### 9.2 格挡规则
- 格挡是临时值：玩家 T1 清零、怪物 T3 清零。
- 伤害结算链（沿用 v1 §4，唯一公式）：`基础+面板加成 → 力量/易伤修正 → 护甲减免(穿透) → 格挡吸收 → HP`。

### 10.1 职业战斗配置 `config/battle_roles.json`

## 11. 前端 UI 设计（杀戮尖塔 2 风格）

```
┌──────────────────────────────────────────────────┐
│  战斗背景                                          │
│  ┌────────┐      [⚔撕咬8]      ┌─────────┐      │
│  │ 玩家立绘 │      [🛡格挡6]      │ 怪物立绘 │      │ ← 意图气泡
│  │ 名字/HP  │                   │ 名字/HP  │      │
│  │ 状态图标 │                   │ 状态图标 │      │
│  └────────┘                   └─────────┘      │
│  [专属资源条 炁▮▮▮▯▯] [能量池 AP 12/18]            │ ← 资源条+能量池
│  [普攻2] [技能Q:6] [技能W:5] [技能E:8] [换装⚙]     │ ← 行动条(含AP费用角标)
│  [快捷栏消耗品 ①②③]  [结束回合]                    │
└──────────────────────────────────────────────────┘
```
- **专属资源条**：显示职业资源（炁/子弹/架势…），主动型显示当前值，被动型显示"累积进度条"（如武士架势）。
- **AP 费用角标**：技能/普攻格左上角显示费用，AP 不足灰锁。
- **换装按钮 ⚙**：战斗内打开六槽装备界面，换装时显示"消耗 5 AP / 3 AP"提示。

## 12. 与现有系统对接

### 12.1 引擎层（`battle_engine` + `actionSystem.js`）
- 保留 C++ 状态机骨架；`battleStart` 注入职业配置（能量骰/资源/普攻模板）+ 怪物意图。
- `battlePlayerAct` 分支：`attack(普攻按武器模板) / skill(按 skill_battle) / item / equip(换装扣 AP) / end`。
- 新增 `battleIntent`、状态结算、资源条结算内部函数。
- JS fallback 同接口同步实现。

### 12.2 handler 层（`battleHandler.js`）
- `battleAction` 扩展：`{action, skillId?, itemUid?, equipSlot?, targetIdx?}`。
- 换装：调用 `itemEngine.equipItem`（战斗中允许）+ 扣 AP + 重算战斗快照。
- 战斗内技能不再走旧 `useSkill`（KP 叙事保留给场外/非战斗）。

### 12.3 前端（`client.js` / `battleScene.js`）
- `battleTurn` → 更新 AP 池 + 专属资源条 + 技能费用灰锁 + 意图气泡。
- `battleEvent` → 血条/格挡/状态/资源实时更新（`updateStatus` 扩展 statuses/block/resource/intents）。
- 换装界面战斗内可用，`equipChanged` 同步重算战斗快照。

### 12.4 探索回合值共存
- 战斗暂停探索回合值；战斗行动不耗探索回合值；战斗胜利奖励少量探索回合值（+0.25）。
- 换装消耗的是**战斗能量（AP）**，与探索回合值无关。

### 12.5 克苏鲁锁
- 锁名锁描述，不锁意图行为与数值。

### 12.6 战利品
- 胜利 → 现有掉落；精英/BOSS → 「三选一战利品」。
