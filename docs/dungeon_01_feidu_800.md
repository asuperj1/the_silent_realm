二、副本世界观背景
废都纪元800年，世界壁垒尚且完整但已开始变薄。G314列车驶入青峰山隧道瞬间，一道来自万物归一者——犹格·索托斯（Yog-Sothoth） 的时空裂隙将整列火车吞入独立闭锁的异空间。

列车的真实物理规则与外来虚空扭曲规则并行运转。一群来自遥远星系、追随裂隙而来的米·戈（Mi-Go） 将列车当作狩猎场，利用其密闭环境、广播系统和遇害者的记忆进行拟态猎杀。更深处，一只被裂隙召唤的原始修格斯（Shoggoth） 蛰伏于天花板夹层，静待猎物自投罗网。底层间隙间，成群无形之子（Formless Spawn） 如活体沥青般缓慢渗透扩散。

副本玩法：自由全域探索、搜集线索、分辨真伪、抉择救人、寻找逃生路径。无固定流程、无强制判定、无数值惩罚。

三、副本常驻NPC
1. 陈慧 —— 核心善意原生NPC
身份：G314列车原乘务员，整片副本唯一真实人类幸存者
状态：全程理智清醒，未被虚空污染，已观察记录米·戈的伪装规律长达数小时
位置：4号餐车储物间（锁门躲藏中）
行为逻辑：

主动给玩家全部真实避险提示
能准确分辨米·戈伪造的广播与人声：「广播里说"安全"的那个声音，咬字太干净了，真人不会那样说话」
掌握唯一正确逃生路径：侧壁紧急虚空疏散通道
双结局机制（玩家自由抉择）：

结局	条件	结果
结局A：成功解救	找到陈慧并全程同行抵达逃生通道	肉身与意识完整存活；触发跨世界长线彩蛋链（→渔村1200年）
结局B：未解救/遇害	未找到陈慧，或在途中让她被修格斯吞噬	记忆被米·戈掠夺；人格被拟态借用误导后续来客；所有跨世界彩蛋永久关闭
四、敌对怪物设定（克苏鲁神话体系）
一、无形之子（Formless Spawn of Tsathoggua）—— 底层渗透者
属性	数值
HP	15/只（群体共享斥力场，3只以上每只+5）
伤害	接触 = CON×0.3（取整，最低3）
探测范围	声音≥20分贝 范围2节车厢 / 光源≥50流明 范围1节车厢
形态：黑色半液态粘稠体，从6号车厢门缝、通风口、行李架缝隙缓慢渗出，聚合时形成不定型触须团块，单体如篮球大小。

习性：

依靠声音、振动、光源三重追踪猎物
不瞬间强攻，以缓慢渗透压缩逃生空间为核心策略
火光/强光可使其退缩（光照范围内移动速度减半）
单个威胁有限，4只以上围拢则每回合群体伤害×1.5
应对方式：

静步通过（行动输入需明确"不发出声响"）
使用光源道具驱退
直接战斗：STR≥60可徒手击退单只（消耗HP=CON×0.2），装备武器按battleCore.js公式计算
二、米·戈（Mi-Go）—— 核心诡敌
属性	数值
HP	不直接战斗
拟态精度	广播拟态 = 85%；人声拟态 = 70%；视觉拟态 = 60%
记忆读取范围	已被害乘客的记忆库 = 6人份
形态：粉红色甲壳类真菌生物，头部为布满触须的球状体，膜质翅膀收拢时伏于天花板四角。正常情况下不现真身。

能力体系（全数值判定）：

能力	描述	玩家对抗阈值
记忆读取	掠夺遇害者记忆、情报、声音	被动能力，无法阻止
广播伪造	篡改列车广播系统，播报虚假安全指引	PER≥65→识破广播语气异常
人声拟态	模仿受害者声音呼救	PER≥70→察觉声音无呼吸/环境混响
视觉拟态	伪造尸体姿势/列车长制服轮廓	PER≥60+近距离观察→识破拟态细节错误
假尸体陷阱	在关键位置布置拟态尸体引导玩家走向夹层	PER≥55→察觉尸体无腐化气味
核心狩猎逻辑：

先用真实情报获取信任（播放一段真实录音，内容为某乘客生前的安全判断）
再以假情报引导玩家进入6号车厢夹层——那里是修格斯蛰伏区
全程不直接露面，直到玩家识破伪装，才会在玩家孤立时现真身攻击
真相揭露条件：

玩家收集≥3条真实线索（陈慧的情报 + 实地观察记录）+ PER≥60 → 系统提示「你察觉到广播中的异常——那声音太完美了，不像活人说话」
此后所有米·戈伪造信息自动标注为【可疑】
三、原始修格斯（Proto-Shoggoth）—— 高阶潜伏者
属性	数值
HP	无法直接击杀（仅可驱退）
单次攻击伤害	CON×0.8（取整，最低15）
攻击条件	进入2号车厢夹层板区域 / 玩家落单超过3回合
恐惧SAN消耗	初见→自动-15 SAN（WIL≥75→仅-5）
形态：通体漆黑、泛着虹彩光泽的巨大原生质体，蜷缩于2号车厢天花板夹层中，表面不断浮现并消融无数沸腾的眼球与拟足。直径约3米。

行为规则：

全程静默潜伏，不进入夹层区则不会遭遇
只有在玩家被米·戈假情报诱导进入夹层时主动攻击
强光可暂时驱逐（需要≥3个光源同时照射）
修格斯遭遇战流程（无骰子，纯数值）：

阶段	条件	效果
初见	进入夹层区自动触发	SAN-15（WIL≥75→-5）
第1回合	修格斯伸展拟足	范围内全员HP减去自身CON×0.3
第2回合	修格斯凝聚攻击	锁定最近目标，伤害=CON×0.8
驱退方式A	3个以上光源同时照射	修格斯退缩回天花板，逃离窗口开启
驱退方式B	集火攻击累计伤害≥50	修格斯暂时溃散，15秒内穿过夹层撤离
逃跑失败	未在3回合内驱退	修格斯吞噬范围内全部目标（即死判定）

六、核心游玩流程（纯数值判定、无骰子）
阶段零：进入副本
入场事件：列车震动→灯光闪烁→广播传来米·戈伪造的"安全通知"
感知判定：PER≥65 → 察觉广播语音异常（无呼吸停顿、无环境杂音）
未达到阈值 → 显示正常的广播文本（后续可通过陈慧处获取真相）
阶段一：探索搜集
玩家从3号车厢（中段）开始，可向车头（1号）或车尾（6号）方向自由探索。

L2	2号二等座	某乘客手写便签：「广播里说去6号车集合——但我刚刚看到6号车门外有东西在动」	PER≥50
L3	1号驾驶室	列车长尸体颈部黑色粘液（无形之子残留）	检查尸体

阶段二：抉择——真假情报对立
从探索中期开始，玩家将同时收到两组信息：

来源	内容示例	真实性
陈慧（4号餐车广播/直接对话）	「不要往6号车走，侧壁通道在车尾最里面，贴地跑」	100%真实
米·戈（列车广播/虚假人声）	「所有乘客请前往2号车厢集合，那里有紧急出口」	100%虚假（指向修格斯夹层）
数值判定规则（替代骰子）：

玩家行动	判定条件	结果
听到广播后质疑	PER≥65	识别广播语音无环境音混响→判定为可疑
查看虚假尸体	PER≥60且近距离互动	发现尸体无任何腐烂气味→发现拟态破绽
跟随假指引走向2号	无条件跟随	触发修格斯遭遇战
已获取L5+L7线索	自动过滤	自动屏蔽米·戈一切假情报
阶段三：解救陈慧
触发条件：玩家抵达4号餐车，且尚未触发修格斯遭遇战

陈慧交互流程：

解除戒备：储物间门锁死，需要：

敲门并表明来意（自动通过）
或 STR≥55 撬门进入
情报交换：

陈慧告知：米·戈伪装机制、修格斯潜伏位置、逃生通道位置
同时询问玩家是否经过2号车厢（如果经过且安全，她会评估修格斯是否已警觉）
同行规则：

陈慧加入后成为同行NPC
每节车厢移动时，如玩家已提前清退无形之子则该节车厢安全
如未清退：陈慧HP=20；被无形之子攻击时，玩家可选择「掩护陈慧」消耗自身HP×2代替她受伤
解救失败条件：

玩家在找到陈慧之前触发修格斯遭遇战 → 战斗中陈慧储物间门被震开 → 修格斯吞噬陈慧
同行途中陈慧HP归零
阶段四：逃生
唯一正确路线：4号餐车 → 5号卧铺 → 6号尾车厢侧壁紧急虚空疏散通道

6号车厢逃生阶段规则：

步骤	描述	消耗/判定
进入6号车厢	至少3只无形之子正在渗透，通道弥漫虚空毒雾	每停留1回合HP-3（贴地移动HP-1）
穿越渗透区	玩家可选择「潜行穿过」或「强行突破」	潜行：需PER≥55 + 不携带光源 → 不触发战斗；强突：触发与3只无形之子战斗
开启紧急通道	侧壁阀门需要力量扳开	STR≥60 → 1回合开启；STR<60 → 3回合开启（期间每回合HP-3）
贴地撤离	毒雾密度下层最低	爬行通过后HP-5（固定），陈慧同行则她HP-3
