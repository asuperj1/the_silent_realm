# 日之塔纪元1000｜荒野商队护送｜副本设定

## 基础定位

- **位面**：日之塔消亡世界（环法文明体系发源地）
- **时序**：日之塔纪元 1000 年（建成 133 年、文明鼎盛、防线稳固）
- **权限**：仅白刻痕可进入
- **性质**：三大新手副本之一、唯一环系法师转职起源本

## 核心剧情

日之塔依靠「日神余晖魔力」抵御骸骨邪神大军。玩家受委托护送内陆补给商队前往前哨据点，穿越荒野、旧战场、枯骨谷地，抵御沿途骸骨畸变。

## 核心 NPC

**学徒·洛雅（1000 年纯善学徒时期）**：未神选、未黑化、未经历万界绝望。痴迷环法、心怀守护、初见世间疾苦。

## 唯一全局限定福利

全游戏仅此时序可解锁隐藏职业【环系法师】，永久绑定三技能：

1. 主动·余晖环（亡灵压制伤害环）
2. 主动·界域环（空间防御、抑制拟态）
3. 被动·环序共鸣（双环联动削弱畸变，隐藏不显示面板）

> 后世所有时序，永久无法再获取。

## 副本双路线机制

| 路线 | 特点 |
|------|------|
| 近路峡谷 | 短程、遭遇骸骨督军 BOSS 伏击 |
| 远路丘陵 | 规避 BOSS、消耗补给、魔力风暴损耗 |

## 三结局判定

| 结局 | 条件 |
|------|------|
| 完美结局（商队保全） | 可遇洛雅、可转职、解锁全部剧情 |
| 残缺结局（重伤抵达） | 通关，但无法获得环法传承 |
| 失败结局（全灭） | 副本时序脱出失败 |

## 时序硬性隔离

本副本为洛雅纯白起源时期，和 1100 年黑化抉择、终局净化计划完全隔离百年时差。
