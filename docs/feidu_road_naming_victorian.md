# 维多利亚欧式复古废都城市道路命名方案

> 适用世界：废都轮回消亡世界·青峰山废都（纪元 800 前城市文明）。
> 设计目标：道路命名具备"伦敦维多利亚时代"的历史感、可读性、片区逻辑，并与克苏鲁废都的"永夜、虚空、列车、残破"氛围耦合。
> 命名双轨制：英文（欧式）+ 中文（对照），路网编号 `R-##` 便于代码/存档引用。

---

## 二、片区规划与路网逻辑

以**车站区（G314 虚空列车的城市端）**为绝对核心，采用"维多利亚式放射 + 网格"结构：

```
                 [北·城墙 Gate]
                     │
         [西·工业区]──[中央·车站区 Circus]──[东·商市区]
                     │
          [南·河港区 Wharf]── [东南·贫民区]
              [西南·墓园区]   [东·外城废墟区]
```

| 片区 | 英文名 | 核心枢纽 | 路网特征 | 命名基调 |
|------|--------|----------|----------|----------|
| 车站区 | Terminus Quarter | 中央环场 | 放射大道 + 方格网 | 列车/信号/站务 |
| 商市区 | Mercantile Quarter | 市场方场 | 高密度小街 | 行业/货栈 |
| 工业区 | Industrial Quarter | 煤气厂场院 | 宽路 + 场院 | 工厂/码头/炉火 |
| 河港区 | Riverside Wharves | 码头岸壁 | 沿河堤岸 | 航运/桥 |
| 市政区 | Civic Quarter | 市政厅广场 | 宽大道 | 圣徒/机构 |
| 墓园区 | Burial Grounds | 墓园门 | 尽端小路 | 安魂/方尖碑 |
| 贫民区 | Warrens | 济贫院前街 | 密巷/尽端 | 工匠/济贫 |
| 外城废墟 | Outer Ruins | 废墟门 | 虚线断头路 | 虚空/暮光 |

## 四、命名规则约束（防冲突）

1. **全城唯一性**：后缀 + 前缀组合不得重复；同一片区内禁止"同名不同路"。
2. **编号唯一性**：每条路一个 `R-##`，供 `data/`、存档、`dungeon_outlines.js` 等引用。
3. **风格一致**：全部采用欧式后缀词根，禁用现代中文式命名（如"人民路、解放街"）。
4. **克苏鲁耦合**：虚空/暮光/安魂类命名仅允许出现在外城废墟、墓园区、车站区，控制数量 ≤15%，避免稀释历史感。
5. **可扩展**：新区块新增道路沿用同一词根表，编号接续（R-65+）。

## 五、数据落盘建议

命名清单建议固化为独立配置文件（与现有 `config/scenes.json`、`data/dungeon_config.json` 同级）：

```
data/city_roads.json   # 道路命名表（编号/名称/片区/等级/坐标锚点）
```

字段示例：
```json
{
  "code": "R-01",
  "en": "The Great Concourse",
  "zh": "大列车广场大道",
  "tier": 1,
  "district": "Terminus Quarter",
  "anchor": [122, 84]
}
```
