# 高德地图 2D 俯视城市街区绘制规范（游戏内地图界面专用）

> 适用范围：`coc-rpg-game` 前端地图界面（高德式 2D 俯视街区风），用于废都城市区域地图、街道网格、街区地块、建筑与 POI 标注。
> 参考：高德开放平台（Loca 数据可视化图层 / JS API 自定义地图样式体系），本项目按游戏场景做 4 级道路简化。

---

## 一、总体视觉层级（从底到顶）

| 层序 | 图层 | 说明 | 渲染方式 |
|------|------|------|----------|
| L0 | 底图底色 | 米白/纸色，营造复古旧地图质感 | Canvas 底色 / SVG `<rect>` |
| L1 | 绿地与水系 | 公园、河渠、湖泊（废都场景多枯萎绿地、死水渠） | 多边形填充 |
| L2 | 街区地块 | 路网围合出的地块（block），淡色填充 + 细描边 | 多边形（`PolygonLayer`） |
| L3 | 建筑 footprint | 地块内建筑投影（正俯视矩形群），颜色比地块略深 | 多边形 / 图标（`IconLayer`） |
| L4 | 道路网 | 4 级道路，按等级定宽度与颜色 | 线层（`LineLayer`） |
| L5 | 标注 | 路名、POI 名称、区域名 | 文字层（`LabelsLayer`） |

> 关键：**街道是最顶层视觉骨架**——高德风格里路网清晰度 > 建筑细节。建筑统一为"俯视投影多边形"，不做立面。

---

## 二、道路分级（4 级体系）

高德原生道路体系（高速/国道/省道/县道/主干/次干/支路/内部路 8 级）在游戏内压缩为 4 级：

| 等级 | 高德对应 | 用途示例 | 线宽(px) | 描边 |
|------|----------|----------|----------|------|
| 1 级·环线/主干大道 | 高速+国道 | 城墙环道、中央大道 | 10~12 | 橙黄 `#F5A623`，白色描边 2px |
| 2 级·主干道 | 主干道+次干道 | 片区连接道 | 6~8 | 米黄 `#F7E8B0`，白色描边 1.5px |
| 3 级·次级街道 | 支路 | 街区内部主干 | 3~4 | 白 `#FFFFFF`，浅灰描边 0.5px |
| 4 级·街巷/内部路 | 内部路+步行道 | Mews/Alley 小巷 | 1.5~2 | 浅灰 `#E6E6E6`，无描边 |

**绘制规则：**
1. 道路中线 → 按等级外扩成双线（深色核心 + 浅色路肩），模拟高德"路面+边线"观感。
2. 路网以网格为主：主轴横竖正交，次轴斜向放射（对应命名方案中的 Circus 放射结构）。
3. 断头路、环形路自然保留，废都场景允许 10%~15% 的"未建成/坍塌路"用虚线表示。
4. 道路交叉口自动倒圆角（radius ≈ 道路宽度的一半），避免直角生硬。

## 三、街区（Block）绘制规范

1. **围合判定**：街区 = 被 4 级及以上道路闭合围出的最小多边形。同一地块内不允许道路穿过（穿过即拆分为两个地块）。
2. **地块填充**：
   - 正常街区：`#F2EFE9`（米白），描边 `#D8D2C4` 0.5px。
   - 废都废墟区：`#E5DED2`，描边 `#C4B9A6`，允许 30% 地块标为"坍塌"。
   - 绿地/公园：`#E8F0DA`（枯萎版 `#E4EAD0`）。
   - 水面：`#CFE6F5`（死水渠用 `#C9D9E2`）。
3. **最小/最大尺寸**：地块边长建议 40~120px（视地图缩放），面积过小（<400px²）与相邻地块合并。
4. **地块内建筑**：
   - 建筑 footprint 为矩形，间距 2~4px，朝向与最近道路平行。
   - 建筑密度：繁华区 70%、普通区 45%、废墟区 20%。
   - 建筑配色比地块深一档：`#E8E2D6` ~ `#CFC6B4`，重要地标（POI）可用图标层覆盖。

## 四、标注规范（路名 / POI / 区域名）

| 标注类型 | 字号 | 颜色 | 规则 |
|----------|------|------|------|
| 道路名 | 12~14 | `#7A6A4F` | 沿道路走向排版，间隔 ≥200px，不跨地块；平行于道路 |
| POI 名称 | 11~13 | `#333333` | 图标 + 名称，图标优先（车站/医院/教堂/警察局） |
| 区域名（片区） | 16~18 | `#9C8C6B` | 居中于片区，粗体，可带装饰框 |

**POI 图标**：参考高德 44 类元素，本项目裁减为 12 类（车站、市场、教堂、医院、警署、邮局、酒馆、工厂、码头、墓园、市政厅、虚空裂隙点）。

**字号层级总原则**：区域名 > 道路名 > POI 名；颜色饱和度按"底图淡、标注深"。

## 六、绘制步骤（实现顺序）

1. **路网骨架**：先画 1/2 级主干（环线+放射+正交网格），再补 3/4 级支路。
2. **街区划分**：由路网围合自动生成地块（可参考地图算法"planar graph → face 提取"）。
3. **建筑生成**：地块内按密度规则程序化摆放矩形 footprint（伪随机，seed 固定保证一致）。
4. **底图润色**：绿地、水系、废墟斑块。
5. **标注**：路名（沿走向）、POI（图标+名）、区域名。
6. **交互层**（可选）：悬停高亮街区、点击 POI 弹详情（对齐 Loca `selectStyle` 思路）。

> 前端实现建议：SVG 矢量绘制（缩放无损、易标注），或 Canvas 分层渲染（数据量大时）。本项目 `frontend/` 已有地图相关界面，后续地图渲染模块按上述分层拆独立文件。

## 七、与克苏鲁废都场景的贴合调整

- 废都"永夜"氛围：整体降低底图亮度（`#F5F1E8` → `#EFE9DC`），道路描边改暗褐。
- 虚空裂隙点：用 POI 图标 + 紫色描边 `#7A5FA8` 高亮。
- 坍塌路（虚线）集中在废墟片区，暗示灾变后路网残破。
