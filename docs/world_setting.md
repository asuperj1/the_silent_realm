## 一、全局终极世界观

### 1. 宇宙双层结构

宇宙只分两层：**新生主世界** + **无数消亡残旧世界**。

| 层级 | 特性 |
|------|------|
| 主世界（现代人类世界） | 壁垒极厚、规则稳固、无诡异、无超凡。旧日支配者、外神、虚空畸变无法入侵、无法触碰。只有带有「灵能刻痕」的极少数人类能观测、坠入外侧消亡世界。 |
| 消亡世界（旧宇宙残躯） | 寿命枯竭、规则崩坏、时空错乱。所有旧日、虚空怪物只能蚕食消亡世界。 |

### 2. 外神终极逻辑

外神永远打不破主世界。唯一入侵路线：**蚕食消亡世界 → 以残界为跳板 → 逐步逼近主世界壁垒**。消亡世界沦陷越多，现实人类世界越危险。

### 3. 玩家定位

玩家 = 主世界灵能刻痕持有者，可穿梭消亡世界的不同历史时序片段（不是平行世界，是同一世界的过去不同年代）。

### 4. 刻痕三阶体系（全局唯一难度标准）

| 阶段 | 特性 |
|------|------|
| **白刻痕**（初期） | 世界灾厄萌芽、秩序尚存 → 三大新手副本专属 |
| **橙刻痕**（中期） | 世界崩坏、战乱泛滥、异化频发 |
| **暗金刻痕**（终末） | 世界濒临湮灭、虚空全开、SAN 侵蚀极强 |

### 5. 世界线唯一分水岭：日之塔 1100·洛雅终局抉择

全世界观只有两条互斥世界线，决定所有彩蛋、NPC、剧情存续：

- **A 线·洛雅失败（真实主线）**：所有世界继续轮回、苦难延续。所有救人彩蛋（陈慧、艾拉、渔村新娘）全部保留有效。
- **B 线·洛雅成功（死寂资源线）**：全域生灵净化、所有活人因果抹除。所有跨世界 NPC 彻底从未存在、彩蛋全部消失。世界只剩死寂残骸，纯资源副本。
