游戏整体系统整合文档（修改版）
整合来源：《我打造了旧日支配者神话》寂静之地、《轮回乐园》 调整内容：
背包规则修改：副本内资源设定全部可以带出副本，不再销毁；取消副本临时区与外来携带区的销毁逻辑；
装备品质序列重定义：白绿蓝紫金橙红；黑色为 BOSS 专属、绑定、可成长稀有装备；
保持：全局通用底层系统，不绑定单一副本；已移除烙印 UI 模块、天赋技能模块。 冲突消解：摒弃副本物品自动销毁规则；保留 SAN 精神体系、阶位仅权限不加属性、不直接抹杀的 TRPG 逻辑。
【本轮交付汇总】
更新背包资源可全部带出副本；
重写全套装备品质体系，黑色定位为 BOSS 专属绑定可成长装备；
其余原有全局模块逻辑保留不变；
所有副本共用该套底层，副本仅填充剧情、怪物、掉落表。

模块 1：角色面板系统【全局通用】
来源：寂静之地神选者面板 + 轮回乐园契约者属性
基础属性（轮回乐园）
成年男性基准值 = 5；属性不会随阶位自动上涨，仅可通过：外来装备、全局天赋、剧情永久奖励获取。
力量：近战伤害、负重、撬锁、破甲判定
敏捷：闪避、先手判定、枪械精准、行动相关判定
体力：生命上限、物理抗性、毒素 / 腐蚀抗性
智力：线索解析、古籍破译、精神抗性、解谜成功率
魅力：NPC 交涉、人质好感、交易折扣
幸运：宝箱品质、掉落概率（极难提升）
全局精神体系（融合两套原著）
SAN 理智值（主数值，区间 080）
6080：清醒，无负面效果
3059：心神恍惚，各类判定获得减值
129：精神错乱，幻觉频发，大额判定减值
0：异化，本轮副本内角色转为游荡畸变单位，本轮淘汰
规则：普通物理攻击、枪械肉搏不会扣除 SAN；只有标记【扣散专属】的事件才消耗 SAN。 临时 SAN 损耗：副本结束自动恢复； 永久 SAN 上限降低：来自窥见旧日真相、高危剧情，不可自然恢复，全局角色永久生效。
意志力（隐藏属性）：降低 SAN 扣减幅度，抵抗精神冲击、旧日侵蚀。
灵魂强度（隐藏属性）：高危装备穿戴门槛，提升畸变污染抵抗。
生存数值
生命值 HP：归 0 倒地，可被救援；不会直接彻底死亡。
行动点：回合制基础，属于游戏回合引擎，不属于两套原著移植内容。
阶位权限体系（轮回乐园，全局生效）
阶位不增加任何属性，仅解锁权限：
允许带入副本的外来装备数量上限
解锁全局商城高阶商品 阶位仅在副本外提升，副本内部无法晋升。
面板附属记录
轮回记录：记录该角色所有副本游玩记录、历次永久 SAN 上限损耗。
素材档案库（寂静之地）：全局档案，跨副本永久保存；自动收录 NPC 证词、古籍文本、怪物记录、异象见闻；侦探类任务可查阅已收集线索。
背包（全局背包规则，副本内获取的所有资源、装备全部可以带出副本，无自动销毁） 
不再区分外来携带区 / 副本临时区；统一一个背包仓库，所有获取物品永久留存角色账号。
可开关选项：可直接关闭阶位系统。

模块 2：副本世界运行机制【全局副本通用规则，所有副本均遵守】
来源：寂静之地轮回机制 + 轮回乐园副本规则
这是游戏底层副本引擎，每一个新做的副本，都继承这套规则，副本只填写自己的剧情、怪物、掉落表。
副本限时机制 每个副本可配置全局倒计时；倒计时结束强制触发副本结算，未完成任务作废。
小队人数 N 动态难度缩放 进入副本的玩家人数为 N；怪物血量、攻击、精神侵蚀强度随 N 线性放大；单人难度最低，人数越多难度越高。
副本轮回重置规则（寂静之地为主） 副本结束执行重置：地图、怪物、物资、NPC 全部复原刷新。
重置不会清除的全局信息：角色记忆、轮回记录、永久 SAN 损耗、素材档案、角色背包内全部战利品； 副本可配置 “底层隐患不重置” 开关：多次轮回后副本内部旧日力量缓慢增强。
任务体系（全局任务模板，副本填充具体内容）
主线任务：生存 / 营救 / 探索，决定副本基础评分。
支线任务：NPC 委托、线索搜集、清理畸变生物。
长线侦探任务模板：多阶段走访取证、物证搜集、密室解谜；固定两套结局：【仓促结局】、【完整真相结局】，奖励与精神代价不同。
互斥抉择分支：多条路线互斥，解锁不同区域、不同掉落池，不可同时拿全部收益。
隐藏触发任务：需要满足前置条件（线索集齐、特定支线完成）才会激活，无前置提示。
副本评分体系（轮回乐园） 评价档位：E < E < D < C < B < A < S < S+ 评分加权三项： ①区域探索完整度；②主线 + 支线完成情况；③角色剩余 SAN 值（剩余越高加成越高）。
可开关选项：可关闭评分，仅保留剧情完成判断；可关闭 “轮回隐患增强”。

模块 3：装备、品质、耐久、掉落系统【全局通用装备规则，所有副本共用】
来源：轮回乐园装备体系
副本可以配置本副本最高掉落品级，装备底层规则全部统一。
品质由低到高（全局固定序列）
白色普通 ＜ 绿色精良 ＜ 蓝色稀有 ＜ 紫色史诗 ＜ 金色华贵 ＜ 橙色传说 ＜ 红色湮灭
黑色：BOSS 专属・绑定・可成长稀有装备
获取来源：仅限特定副本专属 BOSS 掉落；
绑定属性：获取后直接绑定该角色，不可交易、不可转交其他角色；
可成长机制：满足条件（击杀特定目标、消耗特殊素材、完成剧情）可以提升自身词条、属性；
全局装备通用规则
穿戴门槛：力量 / 敏捷 / 灵魂强度，不满足条件无法穿戴。
耐久度系统：每件装备拥有耐久；战斗使用消耗耐久，耐久归零装备直接失效；可通过副本内 NPC、消耗道具进行修复。
词条规则： 
白 / 绿品质：01 条词条
蓝色品质：12 条词条
紫色史诗：34 条词条
金色华贵：45 条词条
橙色传说：56 条词条
红色湮灭：67 条词条，附带高额负面代价
黑色（BOSS 专属可成长）：基础多条强力词条，随成长继续解锁新增词条，自带【角色绑定】标记
套装机制：同系列多件装备集齐，触发套装被动效果。
负面词条：高品级装备允许附带代价 debuff，形成取舍博弈。
装备分类：近战武器、远程武器、防具、饰品、消耗品、生活物资。
背包归属规则：所有副本拾取装备全部存入角色统一背包，可永久带出副本。
强化、吞噬晋升系统：放在副本外全局工坊，不属于副本内行为；副本只产出装备，副本内部不做强化、吞噬操作；黑色装备走独立成长线路，不走普通吞噬强化。
可开关选项：关闭耐久系统，装备永不损坏。

模块 4：资源、奖励、结算系统【全局通用】
来源：寂静之地寂静点数 + 轮回乐园结算逻辑
副本产出全部资源、战利品均可带出副本永久保留。
副本内资源 弹药、绷带、副本本地货币、副本材料；结算之后全部保留在角色背包。
永久全局资源：寂静点数 获取途径：副本结算、高评价奖励、素材档案完整收集、解锁真相结局。 用途：副本外全局商城；购买可带入副本的入场物资、精神防护道具、解锁全局角色相关内容。
副本结算三种触发条件（全局统一） ①副本限时倒计时归零；②全队全部异化淘汰；③完成主线结局主动撤离副本。
路线差异化结算模板（副本可选用，非强制） 副本可以设置互斥路线，不同路线对应不同奖励池、不同精神代价。
全局结算惩罚
中途主动放弃副本：评价降档，背包物品保留，寂静点数仅发放 10%。
角色副本内异化（SAN=0）：本轮副本任务奖励不发放；已拾取到背包的装备物资依旧保留；角色获得永久 SAN 上限下降，角色本体保留，可参与下一次副本。
可开关选项：关闭寂静点数系统，奖励仅保留剧情与战利品道具。

模块 5：异常与惩罚规则【全局通用】
来源：寂静之地、轮回乐园融合；移除副本直接抹杀，适配 TRPG。
HP 归零：角色倒地，队友可救援；多次倒地叠加 debuff，不会直接永久死亡。
SAN=0 异化：本副本内角色变为游荡畸变怪物，本轮副本该角色退出；角色本体保留，施加永久 SAN 上限降低；背包已获取物资全部保留。
窥探未解锁旧日真相：触发大额永久 SAN 上限降低。
穿戴高危黑色成长装备：持续触发【扣散专属】侵蚀，卸下装备即可停止侵蚀。
轮回侵蚀叠加（可选开关）：同一副本多次进入，同等旧日事件 SAN 扣减幅度小幅提升。
## 一、现有界面基础信息 页面名称：调查员档案 视觉规范：纯深色黑底、暗金色按钮文字UI，保持整套界面风格不变 顶部固定导航栏（完全保留不动，不修改）：沉浸档案、全物品图鉴、+新调查员、设置、退出登录 左侧原有结构：角色头像+角色名称职业等级，下方原有3个按钮【技能树、技能加点、仓库】，本次全部删除，不再在侧边展示。 ## 二、核心交互重构规则 1. 左侧角色列表仅做角色展示，点击任意角色条目，弹出/跳转全新独立【角色详情配置界面】，所有角色专属功能全部收纳在此界面，不在主页面散落功能按钮。 2. 详情界面自带返回按钮，点击可回到调查员档案主页面。 ## 三、【角色详情配置界面】五大标签页，整合全部系统模块 ### 标签1：概况（角色基础模块） 1. 角色基础信息：头像、名称、职业、等级、白色刻痕标识 2. 全属性面板：力量、敏捷、体力、智力、魅力、幸运 3. 精神数值面板：SAN理智值、意志力、灵魂强度、HP生命值 4. 资源展示：当前角色持有寂静点数 5. 轮回总览：副本游玩总次数、累计永久SAN上限损耗概览 ### 标签2：背包仓库（装备资源模块） 1. 角色统一仓库背包，所有副本产出装备、消耗品、生活物资永久留存，无副本物品销毁机制 2. 装备品质完整分类：白色普通<绿色精良<蓝色稀有<紫色史诗<金色华贵<橙色传说<红色湮灭；黑色为BOSS专属绑定可成长装备，独立分类展示 3. 装备基础信息展示：穿戴门槛、耐久、词条、套装效果、负面debuff；黑色装备标注【角色绑定、可成长】标识 ### 标签3：技能（原技能功能整合） 1. 技能树完整页面 2. 技能加点操作面板 两者合并在同一标签内，做左右分栏布局 ### 标签4：工坊（锻造强化+吞噬成长模块，副本外专属功能，副本内不可访问） 1. 锻造强化子面板：装备强化、装备耐久修复、无用装备分解 2. 装备吞噬晋升子面板：普通白~红色装备吞噬晋升品质逻辑 3. 独立子分页：黑色成长装备专属养成入口，黑色装备不可交易、不可参与普通吞噬，单独成长养成体系 ### 标签5：档案记录（任务+素材档案模块） 1. 全副本轮回记录：所有通关副本、通关时间、副本评价档位E-~S+ 2. 素材档案库：自动收录NPC证词、古籍、怪物图鉴、异象见闻 3. 任务历史记录：主线支线、互斥路线（救人/装备线）、隐藏任务完成情况 4. 历次SAN损耗明细，区分临时损耗、永久不可逆损耗 ## 四、强制绑定业务底层规则（开发必须遵循，不可改动） 1. 所有副本产出装备、资源均可永久带出副本，无自动销毁逻辑 2. 装备品级规则严格执行：黑色装备仅BOSS掉落、角色绑定、专属成长路线，不参与吞噬晋升 3. SAN数值规则：副本内临时损耗通关自动恢复；窥见旧日真相、高危黑装带来的永久SAN上限降低永久保存于角色档案 4. 锻造、吞噬、装备成长全部仅能在副本外工坊使用，副本游玩过程禁止开放该功能入口 5. 小队N人动态难度、副本限时、评分体系底层逻辑无需在UI实现，仅档案记录展示历史评分结果
