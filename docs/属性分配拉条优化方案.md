# 属性分配模块 · 拉条交互优化方案（王者荣耀物品拉条风格）

> 日期：2026-08-29 ｜ 状态：方案定稿（待实施）
> 范围：详情页「属性分配」模块（`frontend/js/attrAllocate.js` + `frontend/css/main.css` 的 `.attr-slider` 系列）
> 目标：把当前「全属性 0-100 占比滑条」改为**王者荣耀物品数量拉条**式交互——滑块位置 = 该行可分配量比例、与数值严格同步、带刻度吸附 + 快捷档位 + 跟手拖动。

---

## 一、现状与问题分析

### 1.1 当前实现（attrAllocate.js + main.css）
- 每行结构：`−` 按钮 ｜ 拉条（`.attr-track` 内 `.attr-fill` 金色填充 + `.attr-thumb` 发光宝石滑块）｜ `＋` 按钮
- 交互：`pointerdown/move/up`（Pointer Events）+ `requestAnimationFrame` 节流拖动；`+/−` 步进 1；左右方向键步进 1
- 关键计算（`applyDrag`）：
  - 滑块视觉：`thumb.style.left = ratio*100%`（鼠标在轨道 0-100% 的比例，直接跟随）
  - 分配值：`alloc[key] = Math.round(ratio * maxA)`（`maxA = maxAllocFor(key)` 受属性上限 100 与剩余点双重约束）
  - 行内展示：`fill.width = (val+delta)/100*100%`、`thumb.left = (val+delta)/100*100%`（**全属性占比**）

### 1.2 交互问题清单
| # | 严重度 | 问题 | 根因 |
|---|---|---|---|
| 1 | 🔴 P0 | **滑块位置与分配值脱节**：拖动中 thumb/fill 直接跟随鼠标到轨道任意 0-100%，但分配值按 `round(ratio×maxA)`；且非拖动态 thumb 显示的是 `(val+delta)/100`（全属性占比）。两套比例混用 → 鼠标拖到 50%，可能实际只分 4 点（maxA=7），而 thumb 停在 50% 视觉与数值对不上 | 滑块视觉用「全属性占比」，分配逻辑用「可分配量」 |
| 2 | 🔴 P0 | **可分配范围不直观**：剩余点少时（如 maxA=2），鼠标可拖满整条轨道（thumb=100%），用户以为还能分更多，实际已封顶；反之 maxA 大时不知道一格代表多少点 | 轨道整段 0-100%，未按 maxA 划分可用段 |
| 3 | 🟠 P1 | **无刻度/档位**：王者风格滑条有刻度线与快捷档位（1x/5x/10x/最大），当前拖动只能盲拖，颗粒度差（maxA≤5 时轻轻一拖跳 1 点，maxA 大时逐点拖太累） | 无刻度吸附、无快捷步进 |
| 4 | 🟠 P1 | **无「清零/分满」快捷**：把某属性一次分满或清零需拖动或连点 `+/−` | 缺少一键操作 |
| 5 | 🟡 P2 | 拖动中 `+/−` 按钮禁用态不实时刷新（拖完才 render） | 拖动内联更新未同步按钮 |
| 6 | 🟡 P2 | 点击轨道与拖动无区分反馈；无拖动中的数值气泡（跟随滑块显示分配值） | 视觉反馈单一 |

## 二、王者荣耀物品拉条风格参考

王者荣耀商城/背包「数量选择器」的拉条特征：
- 细长水平轨道 + 居中圆形滑块，两端 `− / +` 按钮
- **滑块位置 = 当前数量 / 最大值 × 100%，与数值严格一一对应**
- 轨道上有**分段刻度**（可用单位标记），滑块在刻度上吸附
- 拖动跟手，数值实时刷新；常配**快捷档位**（如 1 / 5 / 10 / 最大）
- 金色/橙色主色调，滑块圆形发光，填充渐变

→ 映射到本模块：**把「全属性占比轨道」改为「该行可分配量轨道」**——轨道代表 `0 ~ maxA` 点，滑块位置 = `alloc / maxA`，拖动时数值 = 鼠标比例映射到可分配量并吸附刻度。

## 三、目标交互设计（核心规范）

### 3.1 核心原则
> **滑块位置 = 该行已分配量 / 该行可分配量（alloc/maxA），与数值严格同步。**

- 轨道语义：`0%` = 不分配，`100%` = 已分满该行可分配量（maxA）
- 拖动过程：`thumb.left = alloc/maxA×100%`（取整后回弹对齐刻度，杜绝视觉脱节）
- `maxA=0`（属性满 / 无剩余点）→ 轨道整体置灰、thumb 停 0%、拖动与 `＋` 禁用

### 3.2 行内元素（新增/调整）
```
[💪 力量]  [−]  [━━━●━━━━━━━━━ 轨道(0~maxA刻度) ━━━]  [+]  [+X] [当前93] [清零][分满]
                        ↕ 拖动滑块 / 点击轨道 / 方向键
```
- **刻度**：轨道按 `maxA` 均分，画刻度点（maxA≤8 每点一格；maxA 大时均分 5 段），滑块吸附到最近整数格
- **快捷档位**：行内右侧两个小按钮 `清零`（alloc→0）、`分满`（alloc→maxA）；可选 `½` 半额
- **数值 readout**：`+X`（本次分配，绿色）+ `当前 Y`（灰）+ 拖动时气泡显示目标值

### 3.3 指针交互
| 事件 | 行为 |
|---|---|
| `pointerdown` 轨道 | 立即定位到点击处对应刻度（`alloc = clamp(round(ratio×maxA))`）→ 吸附 |
| `pointermove`（capture）| rAF 节流，`alloc = clamp(round(ratio×maxA))`，thumb/fill/数值同步，按钮态同步 |
| `pointerup / pointercancel` | 精确落点 + `render()` 统一刷新；`cancel` 回滚到吸附值 |
| `pointerdown` 滑块 | 允许（等同轨道拖动） |

### 3.4 键盘/快捷
- `←/→`（或 `↑/↓`）步进 1（保留）；`Shift+→/←` 步进 5（新增）
- `+/-` 按钮步进 1（保留）
- 快捷按钮：`清零` / `分满`（新增）

## 五、代码实现方案

### 5.1 `frontend/js/attrAllocate.js`

**a) `render()` 行模板改造**（滑块/填充/刻度定位改为可分配量语义）：
```js
const maxA = maxAllocFor(key, attr);
const ratio = maxA > 0 ? Math.min(1, (alloc[key]||0) / maxA) : 0;
const ticks = buildTicks(maxA);          // 刻度 HTML（maxA≤8 每点一格，否则均分5段）
const disabled = maxA <= 0;
// 行内：
//   − 按钮 | 轨道(fill=ratio, thumb=ratio, ticks) | + 按钮
//   readout: +X  当前 Y   快捷: [清零][分满]
```

**b) `buildTicks(maxA)`**：生成刻度点数组（`0..maxA` 均分，映射为 `left%`），并标记 `on`（`tick ≤ alloc` 亮起）。

**c) `applyDrag()` 核心算法**（**修复 P0 脱节**）：
```js
const ratio = clamp01((clientX - rect.left) / rect.width);
const maxA = maxAllocFor(key, a);
const target = clamp(0, maxA, Math.round(ratio * maxA));   // 映射到可分配量并取整
alloc[key] = target;
const r2 = maxA > 0 ? target / maxA : 0;                    // 取整后回弹比例
thumb.style.left = r2*100 + '%';
fill.style.width = r2*100 + '%';
updateTicks(row, target, maxA);                             // 刻度亮起同步
updateReadout(row, target, attr);                           // +X / 当前 Y
updateButtons(row, target, maxA);                           // 拖动中按钮态实时刷新
```

**d) 快捷按钮**：行内 `清零`（`alloc[key]=0`）、`分满`（`alloc[key]=maxAllocFor(key)`）→ `render()`。

**e) 键盘**：保留方向键步进 1；`Shift+` 步进 5。

**f) 指针**：沿用 Pointer Events + rAF；`pointerdown` 加 `.dragging` 类（气泡显示）；`pointerup` 移除 + `render()`。

### 5.2 `frontend/css/main.css`
- 按第四节新增/替换 `.attr-track` / `.attr-fill` / `.attr-thumb` / `.attr-tick` / `.attr-quick` / `.attr-bubble` / `.attr-disabled` 样式。
- 保留克苏鲁暗金质感，轨道缩细（10px→8px）更贴近王者细长拉条。

## 六、边界与约束

| 场景 | 处理 |
|---|---|
| `maxA = 0`（属性 100 或剩余点 0） | 轨道 `.attr-disabled` 置灰、thumb 0%、拖动/`＋`/`分满` 禁用；`清零` 仅在 alloc>0 可点 |
| 剩余点被其他行消耗 | 其他行 `maxA` 实时变化 → 重新 render，滑块按新 maxA 回弹（不越界） |
| 拖动中剩余点变化 | 拖动内 `maxAllocFor` 每次重算，target 钳制在最新 maxA |
| 总分配 ≠ 剩余点 | 允许不分配完（原逻辑）——底部提示「可分配 X 点」；`确认分配` 校验 `total ≤ remainPoints` |
| 触屏 | Pointer Events 天然兼容触摸；`setPointerCapture` 防滑出轨道 |
| 旧存档/低点数 | 无影响（alloc 从 0 起，maxA 自适应） |
