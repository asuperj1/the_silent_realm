## 三、通用引擎扩展设计（核心）

### 3.1 资源获取通用化

在 `battlePlayerAct` 各分支统一提取资源获取，避免散落硬编码：

```js
// 统一资源获取：把「任意触发点 → 资源 +N」通用化
function gainResource(p, amount, src) {
  if (!p.resource || !p.resourceRule || !amount) return;
  p.resource.value = Math.min(p.resource.max || 10, (p.resource.value || 0) + amount);
}
```

触发点接入（新增）：

| 触发点 | 规则字段 | 位置 |
|--------|---------|------|
| 普攻命中 | `gainOnBasic`（已有） | 普攻分支 |
| 回合开始 | `gainOnTurnStart`（已有） | 回合开始 |
| **受击** | `gainOnHurt` | 敌人回合玩家受击处（`battleMonsterAct`） |
| **暴击** | `gainOnCrit` | 普攻/技能伤害>0 且触发暴击 |
| **装填** | `gainOnReload` | 新增「装填」行动或换弹动作 |
| **击杀** | `gainOnKill` | `tgt.dead=true` 处（普攻/技能） |

### 3.2 累积型被动引擎（架势条 / 五段战姿）

玩家单位新增堆叠字段，由 `triggerPassives` 扩展为支持 `trigger` 对象（含步进值 + 阈值）：

```js
// 玩家初始化时从被动配置建立"累积器"：
// passive.trigger = { onHurt: 1, onDodge: 2, threshold: 5 }
// 战斗单位持有：p._acc = { stance: { count, threshold, trigger: {...} } }
function accPassive(p, id, step, msg) {
  const a = (p._acc = p._acc || {});
  const cur = a[id] || (a[id] = { count: 0 });
  cur.count += step || 0;
  if (cur.count >= cur.threshold) {
    cur.count = 0; // 触发后清零重新累积
    // 触发阈值效果（由被动 effect 定义，如招架标记、五段战姿加成）
    return true;
  }
  return false;
}
```

- **武士架势条**：`onHurt` +1 / `onDodge` +2，满 5 → `p._parry = true`（下一次受击抵消：伤害归 0、清空标记）。
- **百夫长五段战姿**：`onCombo` +1（连击段数计数），满 5 → 下段伤害 +50%；连击期间每段 +8% 伤害（`calcDamage` 注入连击加成）。

### 3.3 mix 资源语义

`resourceType === 'mix'` = 被动累积 + 主动消耗（侦探探知值 / 警官正义值）：

- 触发型资源获取（普攻/击杀/回合）照常累加。
- 技能消耗 `costPerSkill` 照常扣减。
- 新增「消耗型特殊动作」：侦探 `markWeak`、警官特殊技能。

### 3.4 侦探「标记弱点」（markWeak）

新增特殊行动 `action === 'markWeak'`（不耗 AP，耗 2 探知）：

```js
if (action.action === 'markWeak') {
  const cost = p.resourceRule.markWeak ? 2 : 0;
  if ((p.resource.value || 0) < cost) return { ok:false, msg:'探知值不足' };
  p.resource.value -= cost;
  const t = pickTarget(b, action.target);
  if (t) { addStatus(t, 'vulnerable', 1, 2); ... } // 目标易伤+1（2回合）
}
```

### 3.5 警官「正义处决」（autoExecute）

每回合开始 / 资源满值时检查 `autoExecute`：

```js
// 回合开始（onTurnStart 后）
if (p.resourceRule && p.resourceRule.autoExecute && p.resource.value >= p.resource.max) {
  const t = pickTarget(b, 'lowest'); // 最低血量敌人
  const dmg = Math.max(p.physAtk, p.magAtk) * 1.0; // 真实伤害（无视防御）
  t.hp = Math.max(0, t.hp - dmg);
  p.resource.value = 0;
  msgs.push(`⚖ 正义值满！触发【正义处决】无视防御造成 ${dmg} 伤害`);
}
```
