| 维度 | 现状（代码内） | 目标（重做后） |
|---|---|---|
| 职业 | 10 个简化职业（1 被动 + 2 主动） | **13 个完整职业**，每职业 1 被动 + 3 流派 × 6~8 技能 |
| 属性 | 7 项（hp/san/str/dex/con/per/wil），无职业倍率 | 保留 7 项，新增**职业基础/倍率/成长**三件套 + 独立资源 |
| 伤害公式 | 无统一公式（散落） | **统一公式**：`基础 + 等级×成长 + 属性×倍率` |
| 防御 | 简单 | **王者式**：格挡→免伤→防御(穿透)→护盾→HP；`减免率 = 有效防御/(有效防御+80)` |
| 装备 | 2 槽（武器/饰品），无数值体系 | **6 槽（头/手/身/腿/靴/挂饰）** + 白/绿/蓝/紫/橙 稀有度 + 小件/大件 + 套装 |

| 资源 | 无 | 每职业专属资源（酒意/战意/炁/子弹/怒气/星能/魔能/剂量/探知/战力/禅意/狂欢/正义） |

## 二、现状系统盘点（用于差异对比）

- **属性**：`config/attributes.json` — hp/san/str/dex/con/per/wil，20~100 区间，含"极值失衡惩罚"。

## 三、数值系统重做（统一公式 + 结算链 + 倍率表）

### 3.1 统一数值公式（所有伤害/护盾/格挡/回复通用）

```
最终数值 = 基础固定数值 + 等级 × 等级成长系数 + 主属性 × 属性倍率
```

- 纯功能技能（buff/标记/眩晕/减伤）：无数值，不套公式。
- CD 规则：释放当回合**不计** CD，下一回合开始倒计时。

### 3.2 伤害结算链（全局统一，真伤仅扣护盾）

```
格挡 → 百分比免伤 → 防御(穿透后) → 护盾 → 扣生命值
```

### 3.3 防御 & 穿透（王者式，服务端 `damage_calc` 改造）

```
有效防御 = 敌方总防御 − 固定穿透
有效防御 = 有效防御 × (1 − 百分比穿透)
有效防御下限 = 0
减免率 = 有效防御 / (有效防御 + 80)
实际伤害 = 原始伤害 × (1 − 减免率)
```

### 3.4 四大基础定位倍率表（文档原表）

| 定位 | 基础HP | 生命倍率 | 基础防御 | 防御倍率 | 攻击属性倍率 | 等级成长 | 主属性 | 定位 |
|---|---|---|---|---|---|---|---|---|
| 坦克 | 80 | 6.0 | 12 | 0.45 | 0.3 | 1.2 | 力量 | 承伤/减伤/护盾 |
| 战士 | 65 | 4.2 | 8 | 0.32 | 0.75 | 2.1 | 力量 | 均衡/持续输出 |
| 刺客 | 40 | 2.5 | 4 | 0.15 | 1.1 | 2.8 | 力量 | 爆发/高穿透/脆 |
| 法师 | 45 | 2.8 | 5 | 0.18 | 1.2(法) | 3.0 | 感知/意志 | AOE/法穿 |

```
HP上限 = 职业基础HP + 体质CON × 生命倍率
总防御 = 职业基础防御 + (力量STR + 体质CON) × 防御倍率
```

### 3.5 BOSS 基准面板（目标：3~4 人小队、6~7 轮击杀；后期多阶段）

```
前期标准 BOSS：总血量 10000 HP ｜ 物理防御 1200 ｜ 法术防御 900
每轮反击分摊压力，不单点秒人；法师削甲优势（法防更低）
```
